# Moon Chariot H5

一個受 Capcom《Three Wonders: Chariot》橫向卷軸射擊節奏啟發的原創 H5 小遊戲。素材、程式與視覺設計皆為新做，適合直接部署到 GitHub Pages。

## Play

- 手機左側搖桿：移動
- 手機右側 FIRE：射擊
- 方向鍵或 WASD：移動
- 空白鍵：射擊

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
